# MASTER WEBSITE SYSTEM

Blueprint awal untuk membangun website reusable yang nantinya dapat dikendalikan melalui Master Admin Dashboard.

## Jalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Roadmap

1. Master Website
2. Master Admin Dashboard
3. API / backend
4. Database
5. Authentication & role
6. Hubungkan Admin → Data → Website
7. Jadikan blueprint reusable untuk banyak website
